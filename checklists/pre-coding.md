# Pre-Coding Checklist

Complete relevant items before substantial implementation. Small tasks can skip items that clearly do not apply.

## Requirements
- [ ] The problem, target users, and desired result are clear.
- [ ] Scope and out-of-scope behavior are recorded.
- [ ] Important unanswered questions are resolved or marked as assumptions.
- [ ] Acceptance criteria can be tested.

## Setup
- [ ] Runtime and version are chosen.
- [ ] Package manager and dependencies are identified.
- [ ] Required APIs and provider accounts are identified.
- [ ] Database and storage needs are decided.
- [ ] Authentication and authorization needs are understood.
- [ ] Required environment variable names are listed.
- [ ] Real credentials are kept out of Git.
- [ ] Required services are separated from optional services.
- [ ] Current prices, quotas, and free-tier limits are checked if relevant.

## Architecture and quality
- [ ] Components and responsibilities are documented.
- [ ] A Mermaid system diagram is included when useful.
- [ ] Data flow and trust boundaries are understood.
- [ ] Error paths for important integrations are planned.
- [ ] Test, lint, type-check, and build commands are known.
- [ ] Security and data handling have been considered.
- [ ] UI design direction is planned before complex UI work.
- [ ] Docker/CI/CD/deployment needs are identified.
- [ ] Work checklist is ready.
