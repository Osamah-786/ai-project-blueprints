# Cursor Rules Template

Use `AGENTS.md` as the shared source of engineering rules. Copy or adapt relevant rules into the project-rule format supported by your installed Cursor version.

Before editing, inspect project files, clarify important unknowns, and keep changes minimal. Protect existing work, keep secrets out of Git, run relevant checks, update necessary documentation, and inspect the final diff.

This reference file is not automatically loaded by Cursor merely because it is stored in this folder. Check current Cursor documentation for the supported rule format and location.
